# HTML-to-Docx Automated Conversion Implementation

## Overview
Implemented an automated HTML-to-Docx conversion workflow that leverages the existing PDF generator's data pipeline to produce Word documents without requiring manual PDF-to-Word conversion or external API services.

## Architectural Requirements Met

### 1. Shared Data Pipeline (Single Source of Truth)
- ✅ Word generator consumes the exact same data object (`dataPayload`) generated by the PDF engine
- ✅ Uses `buildPdfDataFromRequest()` for data preparation
- ✅ No separate database queries or API fetch hooks for Word export
- ✅ Absolute data consistency between PDF and Word outputs

### 2. HTML-to-Docx Automated Conversion
- ✅ Created centralized utility: `src/utils/exporters/pdfToWordConverter.ts`
- ✅ Implemented automated background conversion workflow:
  - **Step 1**: Render document using HTML strings that match PDF layout structure
  - **Step 2**: Pass HTML string to `@turbodocx/html-to-docx` for automated conversion
  - **Step 3**: Trigger automatic browser download of converted `.docx` file
- ✅ No external PDF-to-Word converter sites required

### 3. Layout Preservation (Headers & Footers)
- ✅ **Separate Header/Footer Arguments**: Headers and footers are now passed as separate parameters to the conversion library
- ✅ Official headers preserved:
  - Agency Name: "Department of Environment and Natural Resources"
  - Office Seals: "PROVINCIAL ENVIRONMENT AND NATURAL RESOURCES OFFICE"
  - Document Numbers: Control numbers and travel numbers
- ✅ Footers preserved:
  - Signatures: Official approval sections
  - Dates: Filing and travel dates
  - Contact Information: DENR CENRO contact details
- ✅ Complex tables and formatting maintained

### Header/Footer Separation
The implementation now properly separates header and footer HTML from the main body content:
- **Header functions**: `generateLeaveApplicationHeaderHTML()`, `generateTravelOrderHeaderHTML()`
- **Footer functions**: `generateLeaveApplicationFooterHTML()`, `generateTravelOrderFooterHTML()`
- **Body functions**: `generateLeaveApplicationBodyHTML()`, `generateTravelOrderBodyHTML()`
- **Conversion call**: Uses the 4-parameter signature `HtmlToDocx(bodyHtml, headerHtml, documentOptions, footerHtml)`

### Key Functions

#### `generateLeaveApplicationHeaderHTML(data: any): string`
- Generates header HTML for Leave Application
- Contains official DENR branding and agency information
- Used as separate header parameter for Word conversion

#### `generateLeaveApplicationFooterHTML(data: any): string`
- Generates footer HTML for Leave Application
- Contains official DENR contact information and tagline
- Used as separate footer parameter for Word conversion

#### `generateLeaveApplicationBodyHTML(data: any): string`
- Generates body HTML matching CSF No. 6 format
- Includes all form fields, leave type checkboxes, and certification sections
- Does NOT include header/footer - those are separate parameters

#### `generateTravelOrderHeaderHTML(data: any): string`
- Generates header HTML for Travel Order
- Contains official DENR branding and office information
- Used as separate header parameter for Word conversion

#### `generateTravelOrderFooterHTML(data: any): string`
- Generates footer HTML for Travel Order
- Contains official DENR contact information and tagline
- Used as separate footer parameter for Word conversion

#### `generateTravelOrderBodyHTML(data: any): string`
- Generates body HTML matching government Travel Order format
- Includes travel details, approval sections, and signature layouts
- Does NOT include header/footer - those are separate parameters

#### `convertPdfDataToWord(pdfData: any, requestType: string): Promise<void>`
- Main conversion function
- Uses proper `@turbodocx/html-to-docx` signature with separate header/footer parameters
- Triggers automatic browser download

#### `exportApplicationToWord(request: any, accounts: any[]): Promise<void>`
- Entry point for individual application exports
- Uses same data pipeline as PDF generation
- Ensures data consistency

## Usage Examples

### Admin Panel
```javascript
// In ApprovedForms.jsx
const downloadWord = async () => {
  try {
    // Uses the same data preparation as PDF for consistency
    await generateApplicationWord(request, getAccounts());
  } catch (err) {
    console.error('Word download failed:', err);
    alert('Failed to generate Word document. Please try again.');
  }
};
```

### User Dashboard
```javascript
// In EmployeeDashboard.jsx RequestCard
const handleDownload = async (type) => {
  try {
    setDownloading(type);
    if (type === 'pdf') {
      await generateApplicationPDF(request);
    } else if (type === 'word') {
      // Uses the same data preparation as PDF for consistency
      await generateApplicationWord(request, getAccounts ? getAccounts() : []);
    }
  } catch (error) {
    console.error('Error downloading application:', error);
    alert('Failed to download application. Please try again.');
  } finally {
    setDownloading(null);
  }
};
```
